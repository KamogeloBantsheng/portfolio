## 🚀 How to Run Locally

You don't need any complex build tooling or package installations!

1. Clone or download this repository:
   ```bash
   git clone https://github.com/KamogeloBantsheng/portfolio.git
   cd portfolio
   ```
2. Simply double-click `index.html` to open it in your favorite browser (Chrome, Edge, Firefox, Brave, Safari).
3. Alternatively, if using VS Code, right-click `index.html` and select **"Open with Live Server"**.

## 🌐 How to Push and Deploy to GitHub Pages (Free)

Follow these simple steps to make your portfolio live at `https://kamogelobantsheng.github.io/`:

### Option A: Using the Automated Windows Script
Double-click `deploy-to-github.bat` in this folder. It will guide you through initializing Git, committing all files, and pushing to your GitHub account!

### Option B: Using Git Command Line

1. **Install Git** (if not already installed):
   Download and install Git from [git-scm.com](https://git-scm.com/download/win).
   
2. **Open PowerShell or Terminal** in this folder:
   ```powershell
   git init
   git add .
   git commit -m "Initial commit: Kamogelo Bantsheng portfolio website"
   ```

3. **Link to GitHub and Push**:
   - Create a new public repository on GitHub named `portfolio` (or `KamogeloBantsheng.github.io`).
   - Run:
     ```powershell
     git branch -M main
     git remote add origin https://github.com/KamogeloBantsheng/portfolio.git
     git push -u origin main
     ```

4. **Activate GitHub Pages**:
   - Go to your repository settings on GitHub: `Settings` > `Pages`.
   - Under **Build and deployment** > **Branch**, select `main` and folder `/ (root)`, then click **Save**.
   - Your website will be live in 1–2 minutes at `https://kamogelobantsheng.github.io/portfolio/`!
